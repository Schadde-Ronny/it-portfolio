# Mein Entwickler-Portfolio 🚀

Willkommen in meinem persönlichen Portfolio-Repository! Hier präsentiere ich meine Webentwicklungsprojekte, meine Skills und als besonderes Highlight eine Live-Integration der **Warcraft Logs V2-API** (inklusive Node.js-Backend, OAuth2 und GraphQL).

## 🌟 Über das Projekt
Dieses Portfolio vereint Webdesign mit echter technischer Logik. Neben klassischen Portfolio-Inhalten zeigt es insbesondere, wie man externe Gaming-Schnittstellen (wie Warcraft Logs) sicher anbindet und im Frontend darstellt.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript (Responsive Design)
* **Backend (für API-Features):** Node.js, Express, Axios
* **Schnittstellen:** Warcraft Logs V2 (GraphQL & OAuth2 Client Credentials Flow)
* **Sicherheit:** Verwaltung sensibler Daten via `.env` und `.gitignore`
